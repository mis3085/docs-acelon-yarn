創新與環保的織物未來
#

創新
#

研發團隊具備多元而靈活的開發能力，能幫助應對市場變化趨勢，創造高降碼纖維產品。

責任
#

致力於員工的發展與穩定，並以關懷社會和保護環境為自己的任務，創造更美好的未來。

永續
#

大幅提升環保產品佔比，除了可回收、原液染色纖維，也提供可生物降解以及生物基纖維，降低水資源、石化資源消耗，與供應鏈合作建立節約資源、環境友好的社會消費模式，努力實現環境保護、經濟和永續發展的目標。

最新環保纖維產品
#

回收尼龍纖維 Recycled 原液染色聚酯纖維 (AceColor®ECO) 原液染色聚丙烯纖維 假擦絲/仿棉絲 (ACECOLOR®)

  • 回收尼龍纖維 消費前回收的尼龍6 FDY/DTY/ATY，材料來源於廢棄絲線，讓廢棄品重新被使用。

  • Recycled 原液染色聚酯纖維 (AceColor®ECO) 環保回收聚酯原液染色纖維 AceColor®ECO，以消費後的寶特瓶為回收再製材料，可減少廢棄物，並在織纖過程中賦予纖維顏色，避免產業中最污染與耗能的染色流程。

  • 原液染色聚丙烯纖維 假擦絲/仿棉絲 (ACECOLOR®) AceColor® 原液染色聚丙烯纖維及聚丙烯中空纖維為聚丙烯 (polypropylene) 及色料製成的合成纖維。

關於我們
#

「聚隆纖維」擁有POY、FDY、DTY和ATY的生產能力，是織物產業中可靠的合作伴侶，專注於多種材質絲線、具功能性、具環保性及雙組分絲線。
